# Static event source audit

Audited July 28, 2026. This review covered the seven non-manual static event
rows that did not have a direct source URL. A URL was added only when a current
organizer page supported the specific 2026 event.

## Corroborated

- `in-the-streets-frederick-2026` now points to Celebrate Frederick's 2026
  calendar entry. It confirms September 12, the downtown location, festival
  hours, and the Up the Creek Party.
- `baker-park-summer-concert-2026-06-07` now points to Celebrate Frederick's
  June 7 calendar entry. It confirms the Summer Concert Series at the Baker Park
  Bandshell at 7 p.m.
- `fireworks-baker-park-2026-07-04` now points to Celebrate Frederick's 2026
  calendar entry. It confirms the July 4 celebration, Baker Park, and the
  fireworks display.

## Retired

- `first-friday-june-2026-frederick`: Downtown Frederick Partnership publishes
  First Saturday, not a June First Friday art walk. No organizer page for the
  seeded event was found.
- `carroll-creek-color-launch-2026`: Color on the Creek's official site lists
  its 2026 water-garden season as June 20 through October 17. It says the
  illuminated boats run from November into March, not during the summer. That
  does not support the seeded June opening-weekend boat event.
- `saturday-farmers-market-frederick-2026-05-17`: the official market at the
  Frederick Fairgrounds is Field Fresh Farmers Market, Saturdays from 9 a.m. to
  1 p.m. The seeded row is named West Frederick Farmers Market and starts on
  Sunday, May 17. The current West Frederick market is at 632 Contender Way.
  No one source supports the row as written.
- `fourth-friday-may-2026-frederick`: Downtown Frederick Partnership documents
  First Saturday and Sunday Art Walk programming, but no Fourth Friday event
  matching this row was found.

These four rows were removed from the published static event catalog. This
prevents unsupported or contradicted details from remaining reachable through
event pages, calendar exports, or static route generation. They can return only
after an editor rebuilds them from a direct current source.
