# UX audit — Frederick Radius (2026-07-21)

A deeper, evidence-based pass than the route-by-route UI audit
(`docs/UI_AUDIT_2026-07-21.md`), focused on what actually degrades the
experience for a real local user. Four tracks: navigation dead-ends,
empty/error/loading states, mobile/a11y friction, and the Ask feature.

Every finding cites `file:line`. Severity is by real-world user impact, not raw
count. Status is one of: **FIXED** (this branch), **DEFERRED** (needs a real
approach, flagged), or **DECISION** (a product/owner call, not a defect).

## Honest headline

This is a well-built, well-defended app. Loaders are genuinely fail-soft; empty
states on `/nearby`, `/places`, `/search` always give a way forward; all 376
buttons have accessible names; sheets trap focus; Mapbox failures degrade
cleanly. The real problems cluster into four themes, and only the first two move
the needle much.

---

## Theme 1 — The app states wrong things confidently (trust)

The through-line, and the fastest way to lose a local. The loaders *compute*
honesty signals; the UI was throwing them away.

- **FIXED — `/today` presents partial feeds as an authoritative empty day.**
  `assembleUnifiedEvents` returns `sourceHealth.degraded` with an explicit
  contract (`unifiedEvents.ts:66-69`, "the UI must not present that partial set
  as complete"), and `WhatsOn` destructured only `{ publicEvents }`
  (`today/page.tsx:734`). When a feed timed out the page said "It is a quiet
  day" / "No events on the calendar today" (`today/page.tsx:805-875`). Now reads
  `sourceHealth`, shows a degraded banner, and suppresses the completeness
  claims.
- **FIXED — `/today` "N events today" counted finished + hidden events.**
  `visibleTodayCount = todayAll.length - featureDuplicateCount`
  (`today/page.tsx:746`) counted already-ended draws (which live in the
  collapsed "Earlier today" list). Now counts from `ahead` only.
- **FIXED — `/open-now` empty copy promised a section that wasn't there.**
  "Places with unverified hours appear below" showed even when the likely-open
  list was empty (`open-now/page.tsx:246-255`). Now gated on `likely.length`.
- **DEFERRED — ISR-baked "Now" / "open now" / "closes within the hour" shown as
  live.** `/today` (`revalidate=300`, `page.tsx:152`; program `live` dot
  `:696-699`; daypart picks `daypartPicks.ts:44`) and `/map`
  (`map/page.tsx:143`; `openPlaces` 5-min bucket `:90-97`; dockCaption
  `:180-181`) bake time-relative state up to ~5-10 min stale. An honest fix is
  client-side liveness, not a qualifier hacked into the busiest surface. The
  code is already self-aware of the bound (`map/page.tsx:79-88`). Needs a
  considered approach.
- **LOW — `/search` "N matches" is a silent cap at 50** (`search/page.tsx:187,
  421`); **`/events` footer names every source even when degraded**
  (`events/(list)/page.tsx:130-135`, mitigated by the degraded banner at
  `EventsExplorer.tsx:576-588`).
- **LOW reach — `/map` radius "within reach" falls back to a straight-line
  circle when the isochrone API fails while still claiming travel-time**
  (`RadiusBuilder.tsx:533-564`). Real, but radius mode has no UI entry point
  (`/map?mode=radius` only), so few users reach it.

## Theme 2 — Speed everyone pays for (perf)

Affects every user's first impression.

- **HIGH — `framer-motion` + the bottom-sheet load on every route.**
  `(app)/layout.tsx:10-11` mounts `PlaceSheetProvider`/`EventSheetProvider`,
  which statically import `PlaceSheet` → `BottomSheet` → `framer-motion`
  (`PlaceSheet.tsx:10`, `BottomSheet.tsx:4-11`), mounted at all times as
  `<BottomSheet present={false}>`. ~30-50KB gzip before any sheet opens. Fix:
  `next/dynamic` the sheet bodies, or only mount `BottomSheet` when `present`
  first flips true.
- **HIGH — `/map` embeds ~1,600 places (~1MB) in the client payload**
  (`map/page.tsx:421, 649-654`; already slimmed via `MapPinPlace` at `:90-132`).
  Remaining win is viewport-streamed pins.
- **MED — `RadiusBuilder` (1,598 lines) loads on the default `/map` browse
  path** (`map/page.tsx:32, 292`) though radius mode is unreachable. `next/dynamic`
  the radius branch.
- **MED-HIGH — `/ask` is one 1,665-line `"use client"` island**
  (`ask/page.tsx:32`, `AskFrederick.tsx`). Split below-the-fold panels.
- **MED-LOW — `/my-radius` (`SavedList.tsx`, 1,160 lines) and `/events`
  (`EventsExplorer.tsx`, 921 lines) are large islands** (maps already deferred).

## Theme 3 — Finished features that are invisible (discoverability)

No broken internal links exist (every href/registry tool resolves). The nav
problem is shipped-but-unwired features. **These are DECISIONS** — the audit
could not tell whether they are regressions or deliberately shelved.

- **DECISION — `CountyOverview`** (the "we cover all 12 municipalities" map
  built for `/about`) is never mounted (`components/muni/CountyOverview.tsx`;
  `about/page.tsx` doesn't import it).
- **DECISION — `CostTransparency`** (the "no ad/investor money" credibility card
  built for `/trust`) is never imported (`components/trust/CostTransparency.tsx`,
  data `data/cost-transparency.ts`).
- **DECISION — `/wheel` has zero entry points** (`wheel/page.tsx`,
  `FieldWheel.tsx`); reachable only by typing the URL. Add a link from
  `/compass`, or leave it as an unlisted concept.
- **LOW — ~40 dead components** from prior iterations (pure tech-debt, no user
  impact): most of `components/today/*` old set, several `event/*` rails,
  `discover/LocationAutocomplete.tsx`, assorted `ui/*`, marketing scenes. Full
  list in the nav-track findings.
- **VERIFY — honest-empty tool pages** (`/deals`, `/happy-hour`, `/brunch`,
  `/food-trucks`) have data sources and honest empty states, but a production
  spot-check should confirm none is *perpetually* empty (which would feel like a
  dead-end for a Compass tool).

## Theme 4 — Polish (mobile / a11y / resilience)

Strength first: a full sweep of 376 buttons found **zero unnamed controls**;
form labels, alt text, BottomNav clearance, focus-trapping sheets, and custom
widgets (`TimeScrubber`, `FieldWheel`) are all handled. No horizontal overflow.

- **FIXED — suppressed focus ring on `/plan`.** The area `<select>` and four
  number `<input>`s used `outline-none` with no replacement
  (`PlanBuilder.tsx:715,742,769,782,795`). Added a focus-visible brand ring.
  (The other flagged spots — `LocationAutocomplete` dead code, `BeerIndex` on
  the debt-tracked `/beer` palette — were intentionally left.)
- **DEFERRED (needs axe gate) — sub-44px tap targets on hot paths:**
  `HistoryDeck.tsx:168,183` (36px "On this day" arrows), `MonthGrid.tsx:88,105`
  (36px month prev/next), `NearbyNow.tsx:241` (28px "clear my location"),
  `AppMap.tsx:1870` (~14px geo-error toast ✕), `InstallPrompt.tsx:47` (36px).
  `.tap-44` overlays need per-context checking to avoid stealing neighbor taps;
  verify with `test:ux`.
- **DEFERRED — `/rhythm` tap-to-identify has no keyboard path** (WCAG 2.1.1).
  The canvas has `role="img"` + a label and the week slider/story chips are
  keyboard-reachable, but selecting a dot is `onPointerDown`-only
  (`RhythmField.tsx:243`). Passes axe (has an accessible name) but is a real
  Level A gap.
- **DEFERRED — no route-scoped `error.tsx` for `/today` or `/map`, and the
  shared boundary's "Back to Today" loops back to the crashing route**
  (`(app)/error.tsx:58-65`). A few unguarded synchronous paths on `/today`
  (`buildDaypartRows`, `todayFrame`, `currentSkyPalette`) and `/map`
  (`openPlaces`). Low throw-likelihood, but zero graceful degradation.
- **DEFERRED — `loading.tsx` skeletons shaped to old layouts.** `/today`
  (`loading.tsx:19-39`, cinematic sky + mood tiles that no longer exist) and
  `/map` (`loading.tsx:17-27`, a chip strip that was removed) flash wrong
  content and cause layout shift.

## Theme 5 — Ask ("Ask Radius")

**It does not fabricate data.** Ask retrieves from the real Radius datasets
(hybrid search: embeddings + keyword, `hybrid-search.ts`), then uses an LLM
(Claude Haiku 4.5 via the Vercel AI Gateway, or a direct key) only to phrase and
structure an answer over those retrieved rows, with citations and deterministic
guardrails (`answer.ts` header; `route.ts:14` "Never fabricates — the model only
sees retrieved real places"). Claude is the writer, not the source. With no AI
key it degrades to a coming-soon state.

- **DEFERRED — false-red tests giving a misleading signal.** The 4 `/api/ask`
  "location policy" failures all die on `after()` being called outside a request
  scope (`route.ts:86`, from `main`'s search-miss telemetry), not on the
  location logic — the privacy policy (ignore IP, fall back to whole-county
  unless given a device fix / town / scope) is intact. Fix: mock `after` in
  `route.spec.ts` so the policy assertions actually run. The 5th failure is a
  minor reservation source-ordering drift (`answer.spec.ts`).

## What shipped on this branch (`claude/build-deep-audit-vlf5ap`)

- `fix(trust)`: `/today` reads `sourceHealth` + honest count; `/open-now` empty
  copy. (Theme 1)
- `fix(a11y)`: `/plan` focus ring. (Theme 4)

Not merged to `main`: behavioral changes to `/today` deserve a human glance, and
`test:ux` (axe) could not run in the audit sandbox. Verified locally: `tsc`,
`eslint`, `check-colors`, and full `vitest` (only the 5 pre-existing `main` reds,
zero new). Dev render confirmed `/today` now shows the honest degraded banner in
a feeds-down state where it previously claimed "no events today."

## Recommended next order

1. Theme 2 perf (`framer-motion` off the shared bundle, dynamic `RadiusBuilder`)
   — every user, every load.
2. Theme 4 tap targets + `/rhythm` keyboard path — with a `test:ux` run.
3. Decisions: wire or retire `CountyOverview`, `CostTransparency`, `/wheel`.
4. Theme 1 deferred: client-side liveness for the ISR "now"/open-now claims.
5. Housekeeping: mock `after` to un-red the Ask tests; delete the ~40 dead
   components.
