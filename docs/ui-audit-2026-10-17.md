# UI audit — 17 October 2026

Live pass against production (`https://frederickradius.app`, SHA on
`main` at capture: `fb51fb6e`) plus a code scan of the UI layer
(`src/components`, `src/app` render). Ingest, loaders, ranking, Fair,
and files already open on PRs #1739, #1816, #1826, #1828, #1830,
#1831, #1832, #1833, and #1834 were not edited. Flaws on those PRs
are listed at the end instead.

A second agent is deleting unused code and doing repo-wide lint/type
cleanup. Dead components, unused CSS, unused packages, and general
`any`/lint cleanup are **listed only**. This follow-up PR only moves
matching hardcoded colors onto existing tokens, and patches a11y
labels, focus, 44px tap targets, reduced-motion, UI console /
hydration issues, and banned hours-hedging copy.

## Method

- Playwright Chromium against production, intro dismissed
  (`fr:beta-intro-dismissed:v10`). Viewports: **390×844**, **320×700 with
  `html { font-size: 200% }`**, **1280×800**.
- axe-core WCAG 2.0/2.1 A/AA on each 390px surface.
- CLS via `PerformanceObserver({ type: "layout-shift" })` after a
  4s settle (Lighthouse's CLS source). Full Lighthouse CLI was not run:
  the pinned `lighthouse@13` engine wants Node `>=22.19`; this
  environment is 22.14.
- Overflow, computed radii/shadows, sub-44px targets, hedging words,
  and console warnings collected per page.
- Code: hex vs `src/lib/brand.ts` / `--app-*` tokens, `outline-none`
  without a focus treatment, `framer-motion` without
  `useReducedMotion`, unused-component import scan.

Screenshots (local, gitignored):
`output/ui-audit-2026-10-17/shots/<route>--<viewport>.png`.
A copy of the key frames is also at
`/opt/cursor/artifacts/ui-audit-2026-10-17/`.

`/places/brewers-alley-frederick`, `/events/snallyfest-2026-kickoff`

## Snapshot

The core surfaces are in good shape. axe is **0 violations** on every
requested page at 390px. Horizontal overflow is **0** at 390, 320/200%,
and 1280. CLS is **good** (`< 0.1`) everywhere measured. The shared
header + 1024px reading column is a phone stack on Today/Events/Saved,
not a broken stretch; Compass already uses a two-column grid at 1280.
The live problems that remain are large-text clipping on Today (owned
by open PRs), a few 36–43px controls, missing focus rings on a handful
of `outline-none` fields, and hardcoded hex that already equals a
token.

### 9. Hedging hours copy — standing ban (rewritten here)

Hours copy may not guess. Confirmed hours state the time
(“Open until 9 PM”, “Opens 4 PM”). Unconfirmed hours show
“Hours not confirmed” or omit the line. Banned phrases:
“likely open”, “likely opens”, “call ahead”, “check hours”,
“may be open”, “probably”. This updates `docs/VOICE.md`.

Fixed in this PR (allowed files): `/open-now`, `/emergency`,
map task labels/notes, Ask want-answer facts, plan-preview closed
status, PlanBuilder likely label, EventSmartPairings, WantAnswerPanel,
trust basis, transit “too tight”, field note at JB Seafood.

- `src/components/today/DaypartNeeds.tsx:236` — “Places likely open right now”

- `src/components/today/DaypartNeeds.tsx:812` — “Hours not confirmed; call ahead”
- `src/components/today/TodayPlacePreview.tsx:60` — “Likely open”
- `src/lib/loaders/daypartPicks.ts:157` — “Likely opens at … · check hours” (**#1830**, loaders)
