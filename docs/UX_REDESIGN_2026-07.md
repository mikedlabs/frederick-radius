# UX Redesign 2026-07 — reconciled master plan

Source: the owner's commissioned review (Frederick_Radius_UX_Review_July_2026.docx,
"a decision-first redesign brief"). Core recommendation: **show less, rank
harder, make every surface answer one real-world question** — reposition from
county information system to local decision assistant. Answer first, browse
second.

This document reconciles the review's 24-item backlog (UX-01..24) against the
codebase as of main@#1047 (2026-07-10 night). Every status below was verified
by a 4-agent code audit with file:line evidence — nothing is assumed from the
review's observations alone, because 10 PRs shipped the same day the review
was written and several items were already partly built.

## Topline

- 1 item effectively DONE (UX-16 — onboarding is already progressive).
- 22 items PARTIAL — the raw materials exist (often orphaned or fragmented);
  the work is wiring and subtraction, not greenfield.
- 1 item MISSING (UX-22 recommendation feedback — deliberately last).
- The review's biggest single finding holds: the app HAS an Ask engine,
  ranked loaders, trust language, and card systems — but /today doesn't lead
  with an answer, three surfaces speak three time/scope dialects, and the
  Ask input is literally an orphaned component with zero importers.
