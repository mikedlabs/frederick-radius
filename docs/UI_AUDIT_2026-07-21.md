# UI Audit — every page (2026-07-21)

Static, code-level audit of all 98 routes against the shipped design system
(`CLAUDE.md`, `docs/VOICE.md`, `docs/DESIGN_TELLS.md`). No running app was
available, so this is a code + copy + a11y review, not a pixel/axe pass — run
`npm run test:ux` / `npm run audit:pages` / `npm run shots` (they need prod
tokens + a browser) as the live gate.

## Verdict

A genuinely well-made field guide. Shared chrome is exemplary: skip-link →
focusable `#main-content`, `:focus-visible` brand rings, 31
`prefers-reduced-motion` blocks, `ErrorBoundary`-wrapped content, 58 `next/image`
users, aria-labelled nav. Empty states are honest almost everywhere, the
no-em-dash rule holds in user-facing copy, and tap targets use `.tap-44`
consistently. Reference surfaces to imitate: **/pulse, /food-trucks, /trust,
/numbers, /emergency-vet, /contacts, /m/[municipality], /events/[slug],
/my-radius, /ask, /plan, /shipping, /rivers**.

Findings cluster into five systemic themes.

## Theme 1 — Design tokens were not machine-enforced (process gap, now fixed)

`style-lint` is a VOICE/banned-word linter (it bans "robust", "destination",
etc.), **not a color linter**. There was no automated check for raw hex, so one
surface diverged:

- **`/beer` was built on a separate hardcoded brown/cream palette** — ~136 of
  the ~138 bare `X-[#hex]` Tailwind literals in the entire app UI live in the
  beer components. Every other surface is token-clean.
- Scattered bare hex elsewhere (inline styles / props, not Tailwind classes):
  `/archive` `#d8cfbd`, `/trails` `tone="#1E6B3A"` + TrailsMap legend swatches,
  the first-run `WelcomeFlow` MOOD_TILES, `/report` + `/collect` fallbacks.
- **Token-fallback bug:** `var(--app-brand-2, #2F5470)` rendered **blue** in
  `/amenities` but green in `/parks` for the same Spruce-green token
  (real value `#16352B`). One fallback was simply wrong.

**Fixed this pass:** added `scripts/check-colors.mjs` + `npm run lint:colors`
(flags bare-hex Tailwind color utilities in app UI; allows the `var(--x,#hex)`
fallback form; allowlists marketing/proto and — as tracked debt — `/beer`).
Fixed the `/amenities` wrong-hue fallback, `/trails` IconTile tone, `/archive`
parchment, and the one non-beer Tailwind hit (`/from-above` viewer bg).
**Deferred:** tokenizing `/beer` (~136 literals, 16 files — large; some beer
components were also deleted as dead, see Theme 3) and the WelcomeFlow tile
palette (a visual decision — keep custom vs adopt brand tokens). TrailsMap
legend swatches intentionally mirror Mapbox GL line paint (GL can't read CSS
vars) and are left as a documented exception.

## Theme 2 — Honest-live-data gaps (the app's core thesis)

Surfaces that could manufacture certainty on stale/degraded feeds:

- **/rivers (HIGH, safety-relevant):** a days-old USGS gauge showed its last
  height under a green **"Live"** pill; no per-gauge staleness guard.
  **Fixed:** readings older than 2h now drop to a neutral "Stale" pill (flood
  category still leads when present); the exact age was already shown.
- **/parking (HIGH when the feed is wired; dormant today):** rendered exact
  `"N spaces"` / `"N% full"` with the "crowd-sourced estimate" caveat only in a
  `title=` tooltip (invisible on touch/SR). **Fixed:** counts now read as
  estimates (`~N`), the caveat + observed time moved into the accessible label.
- **/transit (HIGH):** `useLiveVehicles` served the last snapshot indefinitely
  when the feed was down; `fetchedAt` was computed as a staleness signal and
  read by no consumer, so boards showed "N moving now" and ticked a frozen bus
  to "due". **Fixed:** the hook now publishes a reactive `stale` flag (past ~2
  missed polls, re-evaluated each tick so it updates while data is frozen);
  TransitNow swaps the live countdown for "N buses last seen" + "Live feed
  delayed, last update Ns ago", and NextStopsBoard goes "Delayed" (amber, no
  pulse) with neutral per-row ETA markers. RoutePearls glide already clamped at
  the last fix (honest) and the map overlay owns a separate poll — left as-is.
- **/pulse SystemsLedger (MED):** a degraded steady-feed tile still sits under a
  hardcoded "No major changes reported / Checked recently."
- **/beer OnTapNow (MED):** time-only "as of 3:42 PM" reads as today even if a
  day stale.

## Theme 3 — Route & component sprawl / dead code

98 routes; meaningful dead/orphaned code. **Deleted this pass (verified
zero live importers):**

- `/beer`: BeerHero, BeerGuides, BeerPassport, BeerRecs, BeerSectionRail,
  BeerTapHandle, BeerPourPreview, BeerTapListLinks, BeerTapWall (+ `.module.css`),
  BeerTaproomBoard (+ `.module.css`), BreweryScenes, PouringNow, TopShelf.
- `transit/LiveTransitPill`, `pulse/CollapsibleDashSection`.

**Kept (correction to first-pass triage):** the scaffold primitives
`ui/animated-button` (neon-glow), `ui/glass-card`, `ui/gradient-text` are NOT
dead — they're used by the `/pitch` marketing scenes (deliberately separate dark
world). Devibe flags them cosmetically; leave them.

**Flagged for owner decision (feature-like orphans, not deleted):**
`trust/CostTransparency` (docstring says it's on /trust; /trust no longer imports
it) and `muni/CountyOverview` (+`CountyOverviewLazy`) (docstring says /about;
/about was rewritten and dropped it). Re-wire or remove — both are recoverable
from git if wanted, so left in place rather than deleted unilaterally.

**Redundancy:** the `/beer` "explorer" re-ships the whole page's
search/browse/map; `/nearby` vs `/open-now` are indistinguishable in CompassHub
copy though the UX differs (rewrite the two registry descriptions).

## Theme 4 — Voice slips (rare, real)

**Fixed this pass:** `/report` consent grammar ("acknowledges" → "acknowledge
our" — it's legal-consent microcopy on a public form); `/archive` staccato-
fragment hero → complete sentences; "Events Calendar" → "Events calendar";
"Today's Fact" → "Today's fact"; `/happy-hour` rhetorical three (body + meta);
`/parking` all-caps "BANNED" → "not allowed"; `/collections/[slug]` footer
fragment (missing period, mid-sentence cap); `/dear-frederick` label mismatch
("Add" vs "Write your own").
**Deferred:** `/rhythm` metaphor ("changing of the guard").

## Theme 5 — Interaction / a11y spots

**Fixed this pass:**
- **/report + /collect emoji-as-icons** → lucide (DESIGN_TELLS). Report keeps
  its data `glyph` in the shared `categories.ts` for the internal admin view;
  the public form + collect picker render lucide via UI-side maps.
- **/search double brand-lead** — the generic Ask CTA is now suppressed when a
  direct answer lead is present (one primary action).
- **/pulse micro-labels** floored at 10px (were 9–9.5px, WCAG-AA risk).

**Still open (need visual judgment / a design call):**
- **/rhythm (HIGH):** `role="img"` canvas also has `onPointerDown` tap-to-
  identify — unreachable by keyboard/SR. Add a non-canvas inspect path or drop
  the affordance (product decision).
- Sub-44px targets that deliberately overlap: `/history` timeline ticks (~8px),
  `/overhead` + `/rhythm` map markers (26px) — enlarging blindly would create
  overlapping hit areas; needs a rendered pass (presentational ribbon vs
  companion list).
- **/today (MED):** ~12 stacked rails, no single lead action (owner call —
  defensible as a hub).
- **/welcome:** MOOD_TILES raw hex (visual decision, see Theme 1).
- **/styleguide:** publicly reachable (noindex only, no prod gate) unlike
  `/proto/*` — consider the same `VERCEL_ENV === "production"` → `notFound()`.

## What's exemplary (protect)

Gating maturity is unusually high — three fail-closed gates (admin Basic Auth,
beta wall, `/proto` prod-404) + capability tokens. `/events/[slug]` derives one
primary action by priority (Tickets → RSVP → Venue → Official → Directions).
`/my-radius` has the best empty state ("not a rhetorical trio"). `/ask` is the
strongest a11y surface. `/food-trucks` refuses fake pins on principle. `/pulse`
requires BOTH nothing-active AND every-urgent-feed-answered before "all clear".
