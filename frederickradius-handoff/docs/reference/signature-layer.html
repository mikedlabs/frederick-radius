Lever 02 · The clock

An interface that knows what time it is

A local guide has one advantage no design system can fake: it lives in real time. So the surface should change with the actual day. Same screen, same data pipeline, three moments. Palette, copy, and content all follow the clock, and after sunset the field guide becomes a night guide.

Implementation is one theme token set per daypart applied at the layout level, driven by sunset time you already pull with the weather. Copy keys off the same clock. This costs a weekend and it is the kind of detail people screenshot, because no national app will ever feel this local.

Lever 04 · The touch

The card you tap becomes the page you land on

The single strongest expensive signal on mobile is the shared element transition: nothing teleports, the thing you touched expands into the detail with spring physics. Every navigation in the app should feel like this one.

Tonight and tomorrow

In your stack this is framer-motion layoutId for in-page elements and the Next.js View Transitions API for route changes, with vaul already handling sheet springs. Motion rules: springs only, 250 to 400 ms, always interruptible, and nothing animates that the user did not cause. A linear fade is the polyester of motion.

The rules of expensive

What separates high-end from overworked is where you refuse to spend. Paste these under the operating rules in CLAUDE.md.

R1One signature, everywhere. The Radius line owns load, pulse, rule, and confirm. Nothing else in the interface gets to be clever.
R2Motion is physics or nothing. Springs, 250 to 400 ms, interruptible, user-caused. Decorative animation is deleted on sight.
R3Imagery leads editorial only. Picks, gems, and plans get the drone treatment. Lists, results, and civic data stay typographic and fast.
R4The app follows the clock. Daypart drives palette and copy from the sunset time you already fetch. Night mode is a different mood, not inverted colors.
R5Texture at two percent. Grain and glass are felt, never noticed. If a screenshot shows the trick, halve it.
R6Wow ships after subtraction. This whole layer is session five. Applied before the kill list, every one of these techniques would just be premium paint on clutter.
