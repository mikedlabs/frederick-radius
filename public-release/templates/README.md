# Frederick Radius

> Public project hub · Frederick County, Maryland · Beta

[Frederick Radius](https://frederickradius.app) is an independent local discovery project for Frederick County, Maryland. It helps people find useful things nearby without making them sort through a wall of links.

This repository is the public front door for product updates, bug reports, feature ideas, and plain-language documentation. It is deliberately separate from the production application.

## Start here

- **Use Frederick Radius:** [frederickradius.app](https://frederickradius.app)
- **Something is not working:** open a [bug report](../../issues/new?template=bug_report.yml)
- **Have an idea:** open a [feature request](../../issues/new?template=feature_request.yml)
- **Need help:** read [SUPPORT.md](SUPPORT.md)
- **Found a security issue:** follow [SECURITY.md](SECURITY.md) and report it privately

## What belongs here

This public hub contains:

- product and architecture overviews;
- the public data-handling boundary;
- contribution, support, conduct, and security guidance; and
- structured issue forms for useful feedback.

It does **not** contain the production application source, private infrastructure, credentials, provider payloads, curated place or event records, photography, brand asset masters, internal audits, deployment workflows, or Git history from the private production repository.

That separation is intentional. It gives the community a clear place to follow and improve the product without redistributing data or materials that Frederick Radius does not have permission to publish.

## How Frederick Radius treats local information

Local information changes quickly. Frederick Radius aims to:

- identify the source behind factual listings;
- distinguish a confirmed fact from a tip, report, estimate, or preview;
- show freshness or verification status when it matters;
- avoid turning emergency reports or calls for service into claims about a person; and
- provide a correction path when a business, event, route, or place changes.

Read [docs/DATA_BOUNDARIES.md](docs/DATA_BOUNDARIES.md) for the publication rules and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the public system view.

## Contributing

The most useful contribution is a clear, reproducible issue. Please do not post personal information, credentials, private reports, or copied third-party datasets. Unsolicited production-code pull requests are not accepted because the application source is maintained privately.

See [CONTRIBUTING.md](CONTRIBUTING.md) before opening an issue or pull request. Participation is also governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
