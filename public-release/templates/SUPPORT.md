# Support

Use the narrowest channel that fits the problem. That helps Frederick Radius respond without asking you to repeat sensitive information.

| Need                                                              | Best route                                                 |
| ----------------------------------------------------------------- | ---------------------------------------------------------- |
| A page or feature is broken                                       | Open a bug report                                          |
| A product idea or missing use case                                | Open a feature request                                     |
| Incorrect place, event, transit, or deal information              | Open a bug report and include a current first-party source |
| A suspected security vulnerability                                | Follow [SECURITY.md](SECURITY.md); do not post publicly    |
| Privacy, account, business, partnership, press, or licensing help | Email hello@frederickradius.app                            |

## Before posting

- Search existing issues.
- Use a clear title and one problem per issue.
- Include a page link, expected result, actual result, and reproduction steps.
- Remove personal information, credentials, private messages, exact live location, and notification contents.

Public issues are visible to everyone. Frederick Radius may remove content that creates a privacy, safety, legal, or data-rights concern.

## Limits

Frederick Radius is an independent beta project. Support and resolution times are not guaranteed. The service is not an emergency channel, official public-safety service, transit authority, government record, or substitute for information from the responsible agency or business.

For an emergency, use the appropriate official emergency service.
